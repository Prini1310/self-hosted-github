## What Was Built
A fully functional self-hosted GitHub clone with:
- Git-like object model (blob/tree/commit + SHA-1)
- Branching with fast-forward merge and conflict detection
- Java and Python CI build pipelines with live log streaming
- Exclusive file locking with token-based checkout
- JWT authentication and protected routes
- Race condition safety via file-based mutex
- Full test suite with stress tests and e2e scenarios
- Docker support for deployment
